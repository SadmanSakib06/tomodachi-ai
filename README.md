# Tomodachi AI 🌸

A bilingual Japanese-English small-talk chatbot developed for the Speech Information Processing Theory course at Shizuoka University.

## Features
- Japanese and English conversations
- Context-aware responses
- Short-term conversation memory
- Friendly follow-up questions

## Technology
- Python
- Streamlit
- Google Gemini API

## Run locally
1. Install dependencies: pip install -r requirements.txt
2. Create a .env file containing GEMINI_API_KEY
3. Run: streamlit run app.py

## Academic purpose
This project explores natural small-talk dialogue, conversational continuity, and the limitations of AI dialogue systems.
